# Polaris Python Course

Bu depo, Polaris Python dersi kapsamındaki ödev ve uygulama kodlarını içermektedir.

## 📁 2. Hafta Ödevi (2.hafta ödev/)

- **dsoyad.py**: Kullanıcıdan isim, soyisim ve şehir bilgisi alıp ekrana formatlı olarak yazdırır.
- **harfnotu.py**: Kullanıcıdan alınan vize (%40) ve final (%60) notlarına göre ortalamayı ve ilgili harf notunu (AA, BA, BB, ...) hesaplar.
- **indirim.py**: Kullanıcıdan ürün fiyatı ve indirim oranı alarak indirimli fiyatı hesaplar; geçersiz oran girildiğinde tekrar giriş ister.
- **yaş.py**: Doğum yılı üzerinden yaş hesabı yapar ve 18 yaş kontrolü ile ehliyet alabilme durumunu kontrol eder.
